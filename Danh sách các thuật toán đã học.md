# Danh sách các thuật toán đã học

## 1. Cơ bản
- Two pointers, sliding window, bitmask, binary search, sorting, backtracking, divide and conquer.

## 2. Cấu trúc dữ liệu
- Stack, queue, deque, set/map, prefix structures, segment tree, DSU.

## 3. Xử lý xâu
- KMP, Z, rolling hash, Manacher, Trie.

## 4. Toán
- GCD/LCM, harmonic number, fast power, extended euclid, prime.

## 5. Kỹ thuật nâng cao
- Greedy, DP, sqrt decomposition, Mo.

## 6. Graph và Tree
- BFS/DFS, topo, shortest path, MST, SCC, bridge/AP, tree DP, LCA.
