# String Processing

## Mục tiêu
- Chọn kỹ thuật xử lý xâu phù hợp theo dạng truy vấn.

## Bản đồ chọn nhanh
- Pattern matching chính xác: [[KMP]], [[Z algorithm]].
- So sánh substring nhanh: [[rolling hash]].
- Palindrome dài nhất: [[Manacher]].
- Truy vấn prefix/từ điển: [[Trie]].
