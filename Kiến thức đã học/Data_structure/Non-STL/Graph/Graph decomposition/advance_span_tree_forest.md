# Advanced Spanning Tree/Forest

## Mục tiêu
- Dựng spanning tree/MST rồi xử lý truy vấn nâng cao trên cây.

## Khung chung
- Build MST.
- Tiền xử lý đường đi bằng Binary Lifting / min-max DP.

## Ứng dụng
- Second-best MST.
- Chu trình tối ưu khi thêm cạnh ngoài cây.
- Kiểm tra cạnh có thể thuộc một MST.
