# DSU Problemset

## Gợi ý lộ trình
1. DSU cơ bản (`merge/same`).
2. DSU có kích thước/tổng thành phần.
3. DSU có ràng buộc (parity/weighted/xor).
4. DSU offline (rollback, dynamic connectivity).
5. DSU trong MST/Kruskal và bài đồ thị nâng cao.
