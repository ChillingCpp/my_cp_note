# Queue (`std::queue<T>`)

## Khi nào dùng
- Xử lý theo FIFO (vào trước ra trước).
- Duyệt BFS trên graph/grid/tree.
- Mô phỏng tiến trình theo thời gian.

## Mẫu bài quan trọng
- BFS, multi-source BFS.
- Topological sort (Kahn).
- SPFA (cần cẩn thận worst-case).
- Sliding window fixed/variable size và kỹ thuật multiple pointers.
